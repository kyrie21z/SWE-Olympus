# 受控本地 Python 执行演示说明

`campus_service.py` 是模拟模型返回的构造实现材料。
`check_campus.py` 是独立的 Momus 验收材料，在执行之前单独冻结。

这两个文件不会直接安装成真实校园应用，也不会替换任意任务原本的验收定义。

演示先真实执行并验收 T01 接口任务，再将其不可变输入复制到 T03 的独立目录，并运行实际检查。T03 覆盖：

- 并发报名不超容量；
- 重复报名不重复占位；
- 自动递补最早有效候补；
- 跳过已经取消的候补；
- 主动查询状态。

整个演示中的模型仍然是模拟模型，Python 进程、文件与检查结果是真实产生的。

实现代码仅支持经过审查的本地 Python、纯函数与数据，以及已登记的 `math`、`from threading import Lock/RLock` 导入。不提供自由命令、任意导入、网络、容器平台或生产级恶意代码隔离能力。
