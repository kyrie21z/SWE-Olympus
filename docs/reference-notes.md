# 本次参考与采用方式

用户提供的课堂图片用于提取“左侧导航 → 项目入口 → 工作台内任务列表与详情”的信息结构。本版采用灰绿中性色、留白与简化卡片，自行实现P1基础壳；未复制ASF品牌或将其全部菜单承诺为本项目功能。

读取用户本地 `D:/吴恩达agent` 中的三篇学习笔记：

- `1.6 任务分解-识别工作流程步骤`：采用显式输入输出、独立工作包和模块化接口。
- `4.4 组件级评估`：将契约、存储、路径与前端数据归并各自测试，后续成员维护各自场景。
